# Anonymous worker sessions

Status: **Implemented and unit tested**.

A stable track with conservative worker evidence opens one continuous anonymous session such as `WS-20260719-C1-007`. A lost track closes the session; a returning person receives a new session. `employee_id` remains null. No facial comparison is available.

Worker sessions are separated when tracking continuity is lost. The system does not automatically determine whether separate sessions belong to the same real person.
